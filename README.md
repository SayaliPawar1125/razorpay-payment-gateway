# Razorpay Payment Gateway

A full-stack payment gateway application built using React.js, Vite, Spring Boot, and Razorpay. This project demonstrates how to integrate Razorpay Checkout with a React frontend and Spring Boot backend for online payment processing.

## 🚀 Features

- Razorpay Checkout integration
- React.js frontend with Vite
- Spring Boot backend
- Create Razorpay payment orders
- Payment amount handling
- Payment success and failure handling
- REST API communication between frontend and backend
- CORS configuration for frontend-backend communication

## 🛠️ Technologies Used

### Backend
